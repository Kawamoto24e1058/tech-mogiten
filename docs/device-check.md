# 実機確認チェックリスト

公開した本番URLで、部員のスマホを使って確認します。**iPhone（Safari）と Android（Chrome）を最低1台ずつ**。
結果は「○ / × / メモ」を書き込んで、× があれば共有してください。

確認する端末: ______（機種・OSのバージョン・ブラウザ）

## 1. 開く・ログイン

- [ ] 本番URLのトップが開き、2店舗が表示される
- [ ] レジを開き、合言葉を入れると始められる
- [ ] 一度閉じて開き直しても、合言葉を聞かれない
- [ ] ホーム画面に追加できる（iPhone: 共有 →「ホーム画面に追加」／ Android: メニュー →「ホーム画面に追加」）
- [ ] ホーム画面のアイコンから開ける

## 2. 会計

- [ ] メニューを押すと個数が増え、「−」で減る
- [ ] 文字が小さすぎない・ボタンが押しにくくない
- [ ] 「1,000円」などを押すとお釣りと内訳が出る
- [ ] 「会計を確定」で札番号が大きく出る
- [ ] 別のスマホの厨房画面に、すぐ注文が出る（何秒かかったか: ___秒）

## 3. 厨房・呼び出し

- [ ] 「できた」を押すと、呼び出し表示に番号が出る
- [ ] 「音あり」にすると、新しい注文で音が鳴る（マナーモードでは鳴らないことがある）
- [ ] 「渡す」→ 確認画面 →「札を受け取って渡した」で、一覧から消える

## 4. 電波が切れたとき（重要）

- [ ] 機内モードにすると、レジの上に「オフライン」と出る
- [ ] オフラインのまま会計できる（「未送信」の件数が増える）
- [ ] 機内モードを解除すると、数秒〜十数秒で未送信が0になり、厨房に注文が出る
- [ ] オフラインのままアプリを閉じて開き直しても、画面が開く（ホーム画面から）

## 5. 長時間の使用

- [ ] レジを開いたまま5分置いても、画面が暗くならない
- [ ] 1時間使って、電池がどれくらい減るか: ___%
- [ ] 着信や通知が来ても、戻れば続きから使える

## 6. 会場で（当日と同じ場所で）

- [ ] 各店舗の場所で、キャリアごとに電波が入る（docomo / au / SoftBank / 楽天）
- [ ] 人が多い時間帯でも、厨房に注文が届くまでの時間: ___秒
- [ ] 呼び出し表示のモニター・タブレットが、店先から読める

## 7. 練習後

- [ ] 管理画面 →「設定」→「練習データを消す」で、売上が0に戻る
