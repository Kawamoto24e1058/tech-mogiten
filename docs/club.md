# テック部版（文化祭 2026）

一般公開版（`tech-mogiten`）をフォークした、テック部の文化祭用の版。同じコードを `CLUB_MODE=1` で別の公開先
`tech-mogiten-club` に出す。データの保存場所は別で、一般公開版のデータは読むだけ（引っ越し）。

- 公開: `npm run deploy:club`（一般公開版は `npm run deploy`。どちらを最後にビルドしたかで出す先が変わるので注意）
- 開発: `npm run dev`（:5173 一般公開版）と `npm run dev:club`（:5174 テック部版、引っ越し元は :5173）
- 確認: `node scripts/e2e-club.cjs`（2つの dev を起動した状態で）

## できること

| 画面 | URL | 使う人 |
|---|---|---|
| 引っ越し | `/move` | 各店の代表者（前のURLの管理用リンクを貼る） |
| 配達センター（管理） | `/hub/admin` | 中心の店（テック部）の管理用リンクを開いた端末 |
| 配達の注文 | `/hub/order#k=…` | 届け先（屋内展示・Grokの模擬店）の係 |
| 配達係 | `/hub/courier#k=…` | 配達係 |

- 配達の注文は、届け先の係が代わりに入れる。両方の店のメニューから選べ、各店の厨房にはその店の分だけが届く（伝票に「配-N → 届け先」）
- 配達の注文は呼び出し表示に出さない。お金は届けたときに配達係が受け取り、配達料はなし
- 各店の売上には入れるが、「あるはずの現金」には配達係から受け取るまで入れない（売上タブに「配達係から未精算 ◯円」）
- 配達係の画面に「手元のお金: テック部へ◯円・Grokへ◯円」。各店のレジに渡したら「◯◯のレジに渡した」を押す

## 1日目の夜にやること（2日目からテック部版に切り替える）

1. 1日目の営業を終え、前のURLでレジ締めまで済ませる
2. テック部の代表: 前のURLの管理画面「設定 → リンク → 管理用リンク」をコピー → テック部版の `/move` に貼って「引っ越す」
3. Grok の代表: 同じように Grok の店を引っ越す
4. 各店の代表: テック部版の管理画面「設定 → 管理用パスワード」でパスワードを決め直す（パスワードは引っ越せない）
5. 各店の代表: 引っ越し後の画面に出る「新しい部員用リンク」を部員の LINE に送り、全員に一度開いてもらう
   （呼び出し表示のモニターも、新しいURLの `/店舗ID/display` を開き直す）
6. テック部の代表: テック部版の管理画面のサイドバー「配達センター」→「テック部を中心に配達をはじめる」
   → Grok の部員用リンクを貼って店を足す → 届け先「屋内展示」「Grokの模擬店」を足す
7. 各届け先の係に「配達注文用リンク」、配達係に「配達係用リンク」を送る
8. 部員で一度、配達の注文 → 両方の厨房で「できた」→ 配達係で受け取り・届けた・レジに渡した、まで試す
   （試した注文は、各店の管理画面「注文」から削除する）

- 前のURLはそのまま残る。テック部版で困ったら、前のURLに戻って営業を続けられる（ただし戻った間の注文は、テック部版には入らない）
- 前のURLで営業を続けたあとにもう一度引っ越すと、テック部版の内容は前のURLの内容で上書きされる（テック部版で受けた注文は消える）
