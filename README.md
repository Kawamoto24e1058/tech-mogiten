# 模擬店 会計システム

文化祭の模擬店向けの会計システムです。**各部・クラス・団体が自分の店舗をつくって**使えます。要件は [docs/requirements.md](docs/requirements.md) にあります。

- レジ・厨房・呼び出し表示・管理の4画面。スマホでもPCでも、URLを開くだけで使えます
- 店舗ごとにデータを完全に分けています（1店舗＝1つの Durable Object）。店舗の一覧はどこにも公開しません
- 電波が切れてもレジは会計を続けられます。回線が戻ると自動で送信します

## 使い方

1. 代表者がトップの「新しい店舗をつくる」から店舗をつくる
2. 出てくる **管理用リンク**（代表者だけ）と **部員用リンク**（部員に配る）を保存・共有する。リンクには推測できないキーが入っていて、パスワードの入力は不要
3. 部員は部員用リンクを自分の端末で一度開く。以後はトップにその店舗が出る
4. 呼び出し表示（`/店舗ID/display`）は誰でも開ける（札番号とメニューだけを出す）

リンクが広まったときは、管理画面の「設定 → 共有リンク」で作り直せます（古いリンクは使えなくなる）。

## 画面のURL

本番: https://tech-mogiten.momotech.workers.dev

| URL | 画面 |
|---|---|
| `/` | 入口（この端末で使っている店舗と担当を選ぶ） |
| `/new` | 店舗をつくる |
| `/店舗ID/join#k=キー` | 共有リンク（開くとこの端末でその店舗が使える） |
| `/店舗ID/register` | レジ |
| `/店舗ID/kitchen` | 厨房・受け渡し |
| `/店舗ID/display` | 呼び出し表示 |
| `/店舗ID/admin` | 管理（売上・メニュー・札・レジ締め・設定・共有リンク） |
| `/admin` | この端末で管理している店舗の売上をまとめて見る |

以前の版で作った店舗（`/a/...`・`/b/...`）は、「保護する」を押すまでリンクなしでも開けます。管理画面の「設定 → 共有リンクで保護する」で、ほかの店舗と同じくリンクで守ってください。新しい店舗は「店舗をつくる」からしか作れません。

## 構成

| 場所 | 中身 |
|---|---|
| `src/` | 画面（React + TypeScript、PWA） |
| `src/sync.ts` | サーバーとの接続、オフライン時の送信待ちリスト |
| `worker/index.ts` | Cloudflare Worker の入口（API の振り分け、静的ファイル配信） |
| `worker/shop.ts` | 店舗ごとの Durable Object（SQLite に保存、WebSocket で配信、キーでの認証） |
| `worker/registry.ts` | 店舗をつくるときの回数制限と記録（一覧は公開しない） |
| `shared/` | 画面とサーバーで共通の型・計算（札の割り当て、売上集計、CSV） |

## 開発

```bash
npm install
npm run dev
```

http://localhost:5173 を開くと、画面と API（Worker・Durable Object）がまとめて動きます。コードを保存すると画面が自動で更新されます。
同じ Wi-Fi のスマホからは、ターミナルに表示される `Network:` のURLで開けます。

ローカル開発では `.dev.vars` の `DEV_SEED=1` により、デモの店舗（`/a/...` と `/b/...`、リンクなしで開ける）がメニューつきで自動で作られます。本番にはデモの店舗はありません。

データを最初からやり直したいときは、`npm run dev` を止めて `.wrangler/state` を削除してください。

### 確認

```bash
npm run typecheck
npm test        # 計算ロジックの単体テスト
npm run smoke   # npm run dev を起動した状態で、API の通し確認（注文がない状態で実行。データが作られます）
```

## 当日の運用メモ

- レジは各店舗1台だけで開いてください。2台開くと画面に警告が出ます
- オフラインの間、レジの上部に「オフライン・未送信◯件」と出ます。厨房には届いていないので、口頭で伝えてください
- オフラインの間は、端末の再起動やブラウザのデータ削除をしないでください（未送信の注文が消えます）
- 開店前は「管理 → 設定 → 営業の準備 → 札をすべて空きに戻す」
- 閉店後は「管理 → 締め」で現金を数えて記録し、「売上 → CSVで書き出す」で保存してください
- リハーサルの後は「管理 → 設定 → 営業の準備 → 練習データを消す」
